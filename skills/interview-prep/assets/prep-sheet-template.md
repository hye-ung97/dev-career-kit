# 🎯 면접 예습 시트 (예상 질문 + 모의답안)

> **이건 대본이 아니라 골격이다.** 모범답안을 통째로 외워 낭독하면 실전 꼬리질문에서 무너진다. 각 답의 **면접관 의도**와 **내부 기작**을 이해하고 **본인 말로** 재구성하라. `[대괄호]` 플레이스홀더는 **반드시 본인 실제 경험·수치로** 채워야 한다 — 지어낸 값을 외우면 "어떻게 측정했나요?" 한 번에 무너진다.
>
> **저장 위치·이름:** 실행 디렉토리 기준 `interview-notes/{지원자}_{YYYY-MM-DD}_prep.md`.
> `{ }`는 실제 내용으로 채운다.

## 2) 이력서·JD 기술 주제 (핵심) — 프로젝트별 여러 갈래 × 갈래별 트리

> **한 프로젝트는 여러 갈래(branch)로 갈라진다.** 실전 면접관은 한 프로젝트를 한 줄기가 아니라 여러 각도로 판다. 갈래는 PSR 조각(P·S·R)과 동작의 전제 3가지(①동시성 ②부분 실패 ③대량·확장)를 각각 깨는 방향에서 나온다. 갈래마다 L1→L4/L5 체인 + 모범답안·의도·함정.

#### 갈래 1-A. {동시성 이중 방어 (분산락 + DB락)}
```
{L1 건별 수동의 위험 → L2 왜 이중 방어 → L3 각 락은 무엇에/어떻게 → L4 락 만료 후 진입 → L5 DB 제약만으로 경쟁 제거?}
```
- **L1 — {질문}?** ({경험형}) "{골격+플레이스홀더}" · 의도: {…} · 함정: {…}
