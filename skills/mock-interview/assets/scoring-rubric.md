# ⭐ 별점 산정 기준 (Scoring Rubric)

> 4단계 피드백에서 별점을 매길 때 **반드시 이 기준을 따른다.** 감(感)으로 주지 않는다.
> **5개 축**(기술깊이·문제해결·커뮤니케이션·구체성·성장)을 각각 1~5점으로 채점한다. 축은 **독립 평가자 3종**이 나눠 맡고(아래 '평가자 그룹' 참조), **종합점수 = 시니어리티 가중 합**으로 낸다(★는 0.5 단위 표기). 종합점수는 4단계 **판정(Verdict)**으로 이어진다.
>
> 이 기준은 실제 **토스식 서버 개발자 면접**의 평가 관점을 반영한다. 핵심 철학:
> - **"쓸 줄 안다"가 아니라 "왜 그렇게 했고, 내부에서 무슨 일이 일어나는지 아는가"** 를 본다.
> - 트러블슈팅은 **해결로 끝나지 않고 "왜 그 해결책이 적절했는가(내부 기작)"** 까지 갔는지 본다.
> - 성과·개선은 **숫자와 근거**로 뒷받침되는지 본다.

## 채점 원칙
- **모르는 걸 솔직히 인정**한 것과 **아는 척 얼버무린 것**은 다르게 본다. 후자를 더 낮게 준다.
- 이력서에 쓴 것을 **실제로 이해하고 있는지**가 핵심. 남의 성과를 자기 것처럼 말하면 감점.
- 한 번 막혔다고 깎지 말고, **꼬리질문에서 회복하는 능력**도 본다.
- 버즈워드("MSA", "최적화", "이벤트 기반")는 **실체를 설명해야** 점수를 준다. 용어만 아는 건 낮게.
- **깊이 레벨(L1~L5)이 기술 깊이 채점의 1급 근거다.** 세션 노트의 주제별 `도달 레벨`을 먼저 보고, 그 층을 방어한 증거가 실제로 있는지 질문 로그로 확인한 뒤 점수를 준다.
- 백엔드 CS·기초 질문은 주로 **기술 깊이**와 **문제 해결·설계** 축에 반영한다. CS 구간은 전체 질문의 약 10%이므로 한 문제의 오답만으로 전체 점수에 상한을 두거나 과도하게 감점하지 않는다.
- CS 질문에서는 실무 경험이나 수치를 요구하지 않았다는 이유로 **경험의 구체성** 점수를 깎지 않는다. 대신 개념을 실제 상황에 적용하는 논리를 본다.
- **오프닝·클로징(컬처핏·협업)은 별도 점수 축이 아니다.** 이 구간에서 드러난 전달력·두괄식 여부는 **축 3(커뮤니케이션)**에 가볍게 반영하고, 협업 스타일·지원동기는 리포트의 '컬처핏·협업 관찰'에 서술로 남긴다. 컬처핏 답변만으로 기술 점수(축 1·2·4)를 올리거나 내리지 않는다.

## 축 1. 기술 깊이 (원리·내부 기작 이해)

> **이 축은 세션 노트의 `도달 레벨`에 앵커링한다.** 감으로 주지 말고, 각 주제에서 지원자가 실제로 방어한 층(L1~L5)을 근거로 삼는다. 여러 주제의 도달 레벨이 갈리면 **평균이 아니라 다수 주제의 층**을 기준으로 하고, 편차를 근거에 적는다.

| 별점 | 도달 레벨 앵커 | 기준 |
|------|---------------|------|
| ★★★★★ (5) | **L5** 또는 L4를 스스로 먼저 짚음 | 내부 동작·트레이드오프를 스스로 설명하고, 실패 모드 질문까지 방어. 제약이 바뀌었을 때의 설계 판단까지 근거 있게 답함 |
| ★★★★☆ (4) | **L4 방어** | 원리(L3)를 확실히 이해하고, 실패 모드 질문 대부분을 방어. 일부 경계 상황에서만 흔들림 |
| ★★★☆☆ (3) | **L3 방어, L4에서 바닥** | 사용법과 원리는 설명하나 "언제 무너지는가"에서 얕아짐. 트레이드오프를 되묻자 인지 부족 드러남 |
| ★★☆☆☆ (2) | **L2까지, L3에서 바닥** | 왜 그 선택이었는지는 말하나 내부 동작을 설명 못함. "기능 구현엔 성공했으나 왜 그렇게 했는지는 모름" 수준 |
| ★☆☆☆☆ (1) | **L1에서 바닥** | 이력서에 쓴 기술의 기본 개념조차 설명하지 못함 |

**레벨 앵커 사용 시 주의:**
- **면접이 얕았던 것과 지원자가 얕은 것을 구분한다.** 면접 모드가 워밍업(필수 L2)이라 애초에 L3를 묻지 않았다면, 그건 지원자의 한계가 아니라 **증거 부족**이다. 이럴 땐 점수를 낮게 주지 말고 **"증거 불충분"으로 표기하고 판단 신뢰도를 낮춤**으로 처리한다.
- 반대로 **표준·심화 모드인데 모든 주제가 L2에서 끝났다면**, 그건 지원자가 L3를 못 넘은 증거로 인정한다.
- **힌트를 받고 도달한 층**(`L4(힌트)`)은 스스로 방어한 것보다 낮게 본다. 다만 그 회복 자체는 축5(성장)의 가점 근거다.

## 축 2. 문제 해결·설계

> 토스가 보는 문제해결력 = **문제 발견 → 원인을 다각도로 파악 → 여러 시나리오 수립 → 돌발상황 대처**.
> 단순히 "고쳤다"가 아니라, 원인을 파고들고 대안을 비교해 근거 있게 선택했는지를 본다.

| 별점 | 기준 |
|------|------|
| ★★★★★ (5) | 문제의 근본 원인을 다각도로 진단하고, **여러 대안을 트레이드오프로 비교**해 근거 있게 선택. 확장성·장애 상황까지 스스로 시나리오를 세워 대응책을 제시 |
| ★★★★☆ (4) | 원인을 정확히 짚고 대안을 비교해 합리적으로 선택. 장애/엣지케이스는 되물으면 답함 |
| ★★★☆☆ (3) | 문제는 해결했으나 **"그때 그 방법을 왜 골랐는지"**가 결과론적. 다른 선택지와의 비교가 약함 |
| ★★☆☆☆ (2) | 증상만 잡고 근본 원인 분석이 없음. "검색해서 나온 방법을 적용했다" 수준, 트레이드오프 인지 없음 |
| ★☆☆☆☆ (1) | 문제 상황을 구조화하지 못하고, 원인·해결의 인과가 성립하지 않음 |

## 축 3. 커뮤니케이션 (전달력)

> 면접은 대화다. 질문 의도를 정확히 잡고, 결론부터 구조적으로 전달하는지를 본다.
> (실제 후기에서 "면접관과 상호 이해가 안 돼 같은 내용을 반복"한 것이 감점 요인으로 언급됨.)

| 별점 | 기준 |
|------|------|
| ★★★★★ (5) | **결론부터(두괄식)** 말하고 근거로 뒷받침. 질문 의도를 정확히 파악하고, 모르는 부분은 솔직히 인정한 뒤 아는 선까지 논리적으로 확장 |
| ★★★★☆ (4) | 대체로 구조적이고 명확. 가끔 장황하거나 결론이 뒤에 오지만 의도 파악은 정확 |
| ★★★☆☆ (3) | 내용은 있으나 서론이 길고 핵심이 늦게 나옴. 질문 의도를 한 번씩 놓쳐 되묻게 함 |
| ★★☆☆☆ (2) | 질문과 답의 초점이 자주 어긋남. 면접관이 같은 질문을 다시 해야 함. 모르는데 얼버무려 대화가 겉돎 |
| ★☆☆☆☆ (1) | 질문 의도를 반복적으로 오해하거나, 답변이 두서없어 전달이 거의 안 됨 |

## 축 4. 경험의 구체성 (숫자·근거·기여)

> 토스뱅크 면접 가이드: 장애 대응·성능 개선·트레이드오프 선택을 **구체적 숫자와 함께** 제시하면 효과적.
> "개선했다"는 말이 아니라 **얼마나, 어떻게 측정했고, 본인이 무엇을 했는지**를 본다.

| 별점 | 기준 |
|------|------|
| ★★★★★ (5) | 성과를 **측정 가능한 숫자**로 제시(예: p99 800ms→120ms)하고 측정 방법까지 설명. **본인 기여와 팀 기여를 명확히 구분**하고, 그 기술을 왜 선택했는지 근거가 붙음 |
| ★★★★☆ (4) | 숫자 근거가 있고 본인 역할이 분명. 측정 방법이나 선택 근거 중 하나가 약간 부족 |
| ★★★☆☆ (3) | 무엇을 했는지는 구체적이나 **정량 지표가 부족**("빨라졌다", "안정화됐다" 수준) |
| ★★☆☆☆ (2) | 경험이 뭉뚱그려져 있고 본인 기여가 불명확("팀에서 했다"). 근거 제시 약함 |
| ★☆☆☆☆ (1) | 이력서 문장을 반복할 뿐, 구체적 상황·행동·결과를 말하지 못함 |

## 축 5. 성장 가능성·학습 태도 (신규)

> 이 축은 **"지금 얼마나 아는가"가 아니라 "막혔을 때 어떻게 반응하고 얼마나 빨리 자라는가"** 를 본다.
> 시니어 면접관이 주니어~미들에게 실제로 크게 보는 신호다. 오늘 모르는 건 배우면 되지만, 막혔을 때 무너지거나 배우려 하지 않는 태도는 잘 안 변한다.
> **모른다고 솔직히 인정하고 아는 선까지 밀어본 것은 이 축에서 가점**이다. 얼버무리거나 우기거나 시도조차 안 한 것은 감점.

| 별점 | 기준 |
|------|------|
| ★★★★★ (5) | 막힌 뒤에도 스스로 가설을 세워 논리를 확장. 자기 답의 한계·트레이드오프를 **먼저** 짚음. 모르는 건 정확히 인정하고 배우려는 태도가 분명. (이전 세션 대비 실제로 회복·성장) |
| ★★★★☆ (4) | 되물으면 논리를 확장하고, 모르는 걸 솔직히 인정. 자기인식이 대체로 있음 |
| ★★★☆☆ (3) | 막히면 멈추지만 얼버무리진 않음. 되물어야 겨우 한 걸음 더. 자기 한계 인식은 약함 |
| ★★☆☆☆ (2) | 막히면 얼버무리거나 화제를 돌림. 모르는 걸 인정하지 않고 아는 척. 되물어도 시도가 약함 |
| ★☆☆☆☆ (1) | 틀린 것을 우기거나 방어적. 배우려는 태도가 보이지 않음 |

> 기술 점수가 낮아도 성장 점수는 높을 수 있고(모르지만 태도가 좋음), 반대도 가능하다(잘 알지만 폐쇄적). **두 축을 섞지 않는다.** 이전 세션 노트가 없으면 "실제 성장" 항목은 빼고 회복력·정직성·호기심·자기인식으로만 채점한다.

## 🧮 평가자 그룹 & 시니어리티 적응형 가중치

4단계 채점은 **독립 평가자 3종**이 나눠 맡는다 (작성자≠평가자). 각 평가자의 축 점수를 아래처럼 **그룹 점수**로 묶은 뒤, **시니어리티별 가중치**로 종합점수를 낸다.

| 그룹 | 담당 평가자 | 묶는 축 | 그룹 점수 |
|------|------------|---------|-----------|
| **기술군** | 기술 평가자 | 축1·축2·축4 | `avg(축1, 축2, 축4)` |
| **커뮤니케이션** | 커뮤니케이션 평가자 | 축3 | `축3` |
| **성장** | 성장 평가자 | 축5 | `축5` |

**시니어리티 적응형 가중치** (JD ④슬롯 또는 이력서 경력에서 정한다. 애매하면 미들로):

| 시니어리티 | 기술군 | 커뮤니케이션 | 성장 | 관점 |
|-----------|--------|-------------|------|------|
| **주니어** (~1년) | 40% | 30% | 30% | 실력보다 자랄 사람인가·기본기·태도 |
| **미들** (1~4년) | 50% | 25% | 25% | 실력과 성장의 균형 (기본값) |
| **시니어** (5년~) | 60% | 25% | 15% | 실력·설계 판단이 최우선 |

**종합점수 계산:**
```
종합 = w_기술 × avg(축1,축2,축4) + w_커뮤 × 축3 + w_성장 × 축5
```

## ⚖️ 최종 판정 (Verdict) — 4단계 성장지향

종합점수를 아래 임계로 매핑해 **"이 답변이 실전 면접이었다면"** 판정을 낸다. 이건 채용 합불이 아니라 **연습용 거울**이다 — 냉정하되, 항상 "다음엔 어떻게 넘을지"를 함께 준다.

| 종합점수 | 판정 | 의미 |
|----------|------|------|
| **≥ 4.3** | 🟢 **강력 추천** | 원리·트레이드오프·태도가 고루 단단. 실전에서 통할 답변 |
| **≥ 3.5** | 🟢 **추천** | 핵심은 방어했고 몇 지점만 보완하면 됨 |
| **≥ 2.5** | 🟡 **보완 후 재도전** | 방향은 맞으나 깊이/근거/전달 중 하나가 확실히 부족. 아래 액션 아이템 후 재도전 권장 |
| **< 2.5** | 🔴 **지금은 부족** | 기본기·이해가 더 필요. 어디부터 다시 다질지 개념 노트로 안내 |

> **판정은 종합점수만으로 기계적으로 내지 않는다.** 아래 **오버라이드 규칙**을 먼저 적용한다:
> - **치명적 결함**(이력서에 쓴 핵심 기술의 기본 개념조차 설명 못 함, 남의 성과를 자기 것처럼 말한 정황) → 종합점수가 높아도 한 단계 강등하고 그 이유를 명시.
> - **성장 신호가 유독 강함**(기술은 얕지만 회복력·정직성이 뛰어남) → 주니어 판정에서 한 단계 상향 여지. 단, 근거를 반드시 서술.
> - 세 평가자의 **판단 신뢰도가 모두 '낮음'**(세션이 짧아 증거 부족)이면 판정을 단정하지 말고 "증거 부족 — 잠정" 표시를 붙인다.

## 종합 별점 산정 예시
```
[미들 지원자 · 가중치 50/25/25]
기술 평가자:   축1=3, 축2=4, 축4=2  → 기술군 = (3+4+2)/3 = 3.0
커뮤 평가자:   축3=3               → 커뮤 = 3.0
성장 평가자:   축5=4               → 성장 = 4.0

종합 = 0.5×3.0 + 0.25×3.0 + 0.25×4.0 = 1.5 + 0.75 + 1.0 = 3.25
→ ★★★☆☆ (3.25 / 5.0), 판정: 🟡 보완 후 재도전
   (기술 구체성(축4=2)이 발목. 단 성장 신호가 좋아 방향은 긍정적)
```
