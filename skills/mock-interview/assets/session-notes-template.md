# 🗂️ 세션 노트 (누적 자산 · 평가 입력)

> 이 파일은 두 가지 역할을 한다.
> 1. **누적 자산** — 다음 세션에서 "지난번 막힌 개념"을 재검증하고 성장을 추적하는 원장(ledger).
> 2. **평가 입력** — 4단계에서 독립 평가자 3종이 **이 파일만 보고** 채점한다. 그래서 여기엔 **증거(무슨 질문에 뭐라 답했고 어디서 막혔나)만** 적고, **별점·판정은 절대 적지 않는다.** (작성자≠평가자 원칙 — 면접관이 미리 점수를 흘리면 평가자가 오염된다.)
>
> **저장 위치·이름:** 스킬 실행 디렉토리 기준 `interview-notes/{지원자}_{YYYY-MM-DD}_session.md`. 같은 지원자의 이전 세션 파일이 있으면 1단계에서 먼저 읽는다.
> `{ }`는 실제 내용으로 채운다.

## 주제·질문 로그

> 실제로 진행한 **모든 질문·꼬리질문**을 순서대로 기록한다. 오프너뿐 아니라 각 꼬리질문도 독립 항목으로.
> 면접관의 관찰은 **사실 기반 증거**로 적는다("~라고 답함", "~에서 막힘", "~를 스스로 짚음"). 점수를 매기지 말고, 평가자가 판단할 재료를 남긴다.
> **`L` 칸(깊이 레벨)은 반드시 채운다.** L1 사실 / L2 선택 근거 / L3 내부 기작 / L4 실패 모드 / L5 설계 판단. 하강 규칙으로 내려갔으면 `L3→L2(하강)`, 힌트를 준 뒤면 `L3(힌트)`처럼 표시한다.
